    Privacy Policy

    MediTime Counter

    MediTime Counter ("the App" or "we") is a pharmacy counter management system that enables shopkeepers to capture prescription and medicine data, automate patient instruction sheets, generate instructional videos, and deliver them to patients via WhatsApp.

    This Privacy Policy explains how we collect, use, process, store, and protect your personal data and the data of your customers (patients). By using MediTime Counter, you agree to the practices described in this policy.

    Data We Collect

    Shopkeeper Data

    • Shop/pharmacy name and address
    • Shop contact phone number
    • API configuration details (Gemini API key, WhatsApp Business account details)
    • App usage statistics (number of prescriptions processed, queue status, timestamps)

    Customer/Patient Data

    The following data is collected from prescription photos and medicine photos:

    Medical Information: Prescription images, medicine packaging images, medicine names, dosages, and schedules are collected and processed.
    • Customer/patient full name
    • Customer/patient phone number (10-digit Indian mobile numbers)
    • Prescription image (photo of physical prescription slip)
    • Medicine packaging images (photos of medicine strips or bottles)
    • Language preference (English, Telugu, or Both)
    • Extracted medicine information with confidence scores
    • Generated schedule sheets and instructional videos
    • Delivery logs (WhatsApp send confirmation)

    How We Use Data

    Primary Purposes

    We process your data to:

    • Read and interpret handwritten prescriptions using AI (Gemini Vision API)
    • Extract medicine information from product packaging
    • Generate deterministic schedule sheets (exact text, no AI generation)
    • Create instructional videos with text-to-speech narration
    • Send patient instruction materials via WhatsApp
    • Track job progress and queue status in real-time
    • Maintain compliance logs and delivery records

    What We Do NOT Do

    ✓ We explicitly do NOT:
    • Use generative AI to create medical instructions (safety risk)
    • Share customer data with third parties except WhatsApp for delivery
    • Sell customer data or derive revenue from data sales
    • Use data for marketing or targeted advertising
    • Store data longer than necessary for service delivery

    Data Processing & Third Parties

    Service Purpose Data Sent Provider
    Gemini Vision API Read handwritten prescriptions Prescription images Google
    WhatsApp Cloud API Send materials to patients Phone, images, videos Meta
    Edge-TTS Voice narration for videos Script text Microsoft
    Data Storage: All prescription images, medicine photos, generated sheets, and videos are stored on your own server (under /media/ directory). No cloud storage is used by default unless you configure it.

    Data Retention & Deletion

    How Long We Keep Data

    • Prescriptions: 90 days after patient receives instruction materials
    • Generated outputs: Deleted with prescription record
    • Delivery logs: Kept for 180 days to prove what was sent
    • API credentials: Kept indefinitely (required for operation)

    User-Initiated Deletion

    ✓ Patients can request deletion: Send deletion request with phone number. We'll delete all personal data within 7 business days.

    ✓ Staff can delete prescriptions: Via Django admin (/admin/) or REST API (DELETE endpoint).

    ✓ Shop owners can request full deletion: All customer records deleted (anonymized delivery logs retained for 180 days).

    Data Security

    Transmission Security

    • ✓ All API communication uses HTTPS with TLS 1.2+ encryption
    • ✓ WhatsApp Cloud API connection is encrypted end-to-end
    • ✓ Gemini API requests are authenticated and encrypted

    Storage Security

    • ✓ Database encryption at rest (enable full-disk encryption on server)
    • ✓ Media files stored with restricted file permissions
    • ✓ Sensitive credentials (.env file) protected
    • ✓ Regular backups stored securely with encryption

    Access Control

    • ✓ Staff login credentials managed by shop owner
    • ✓ API keys restricted to authorized staff
    • ✓ Django admin access (staff-only) requires authentication

    Your Rights & Data Subject Requests

    • Right to Access: Request a copy of all data we hold about you
    • Right to Correction: Correct inaccurate data
    • Right to Erasure: Request deletion of your records
    • Right to Data Portability: Get your data in machine-readable format (JSON/CSV)

    Legal Compliance

    Laws We Follow

    • Medical: Drugs and Cosmetics Act, 1940

    • USA: California Consumer Privacy Act (CCPA)

    Data Breach Notification

    If we discover unauthorized access to personal data:
    • Customers notified within 72 hours (where legally required)
    • Law enforcement contacted if required
    • Full documentation maintained for audit

    International Data Transfers

    Data may be transferred to:

    • Google (Gemini API) - US/Europe data centers
    • Meta/WhatsApp (Cloud API) - US/Europe data centers
    • Microsoft (Edge-TTS) - US/Europe data centers
    • Your own server (location you control)

    For international transfers, we rely on Standard Contractual Clauses (SCCs) for GDPR compliance and adequacy decisions where applicable.

    Children's Privacy

    MediTime Counter is designed for pharmacy staff and adult customers only. We do NOT intentionally collect data from children under 13.

    If a child's data is submitted: Parents/guardians may request deletion via primary contact. Medical records of minors are handled per pediatric privacy standards.
